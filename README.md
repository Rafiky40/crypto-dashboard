# Crypto Dashboard Básico (Portfolio) 🚀
Un pequeño pero elegante proyecto desarrollado con HTML, CSS y Vanilla JavaScript (sin librerías externas ni frameworks). 
## ¿Qué hace este proyecto?
Este proyecto se conecta a la **API pública gratuita de CoinGecko** para mostrar información real del Top 100 de Criptomonedas del mercado en tiempo real. 
### Características principales demostradas:
1. **Consumo de APIs REST (`fetch`)**: Demuestra el uso de funciones asíncronas (`async/await`) para pedir datos al servidor y esperar el resultado.
2. **Manipulación del DOM (`innerHTML`)**: Se inyectan las tarjetas con la información generada dinámicamente, manejando arrays con métodos como `.forEach()`.
3. **Buscador en Tiempo Real**: Implementación limpia del método `.filter()` de JavaScipt que actualiza los datos que hay en la pantalla según se van tecleando letras en el buscador de la página web.
4. **CSS Moderno**: Diseño Dark Mode responsivo utilizando variables de CSS (`:root`), Flexbox, CSS Grid y efectos cristal (Glassmorphism).
---
## 💻 ¿Cómo probarlo localmente?
Este proyecto no requiere ninguna instalación de base de datos ni de Node.js. 
1. Clona o descarga todo el repositorio en tu ordenador local.
2. Haz doble clic sobre el archivo `index.html`.
3. ¡Y listo! Ya podrás visualizar los datos y buscar criptomonedas. 
*(Recomendación: abrir con la extensión "Live Server" en Visual Studio Code).*
